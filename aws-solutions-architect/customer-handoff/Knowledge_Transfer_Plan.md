# Knowledge Transfer Plan

## Audience
Platform engineering, application engineering, security operations, finance partner, and service owner.

## Sessions
1. **Architecture walkthrough — 90 min:** network, compute, database, identity, data flows.
2. **Terraform operations — 90 min:** state, plan/apply, review, recovery from failed apply.
3. **Observability and incident response — 60 min:** dashboards, alarms, severity, runbooks.
4. **Security operations — 60 min:** findings, IAM review, CloudTrail, WAF.
5. **DR exercise — 90 min:** restore sequence, validation, DNS cutover, evidence.
6. **FinOps — 45 min:** tags, budget review, anomalies, rightsizing.

## Handoff Acceptance
Operational owners must be able to:
- identify service dependencies
- execute a nonproduction Terraform plan
- locate logs and alarms
- explain RTO/RPO
- walk through an RDS restore
- triage a GuardDuty finding
- explain the monthly cost review
