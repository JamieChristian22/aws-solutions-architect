# Delivery Plan

Week 1: discovery, evidence collection, current-state map  
Week 2: assessment, risks, target architecture  
Week 3: foundation/IaC/network/identity  
Week 4: application/data/security controls  
Week 5: observability/DR/FinOps  
Week 6: validation, game day, handoff

## Definition of Done
Architecture approved, security controls validated, cost model reconciled, acceptance tests passed, runbook handed off, residual risks accepted.
