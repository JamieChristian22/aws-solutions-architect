# Executive Dashboard Acceptance

## Required KPI Reconciliation
Net Sales, Gross Margin, AOV, Return Rate, Stockout Rate, Sell-Through, and Inventory Turnover must reconcile to governed SQL/semantic definitions.

## UX Requirements
- date/store/channel/product filters
- clear currency/percentage formatting
- last-refresh timestamp
- data-quality status banner
- drill-through from executive KPI to store/product detail

## Decision
Dashboard is accepted only when both data reconciliation and visual usability checks pass.
