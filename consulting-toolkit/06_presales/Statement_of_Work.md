# Statement of Work — Cloud Architecture Modernization

## Objective
Assess and modernize the customer AWS platform to improve security, reliability, automation, and cost governance.

## In Scope
Discovery, assessment, target design, IaC foundation, security controls, observability, DR plan/test, FinOps baseline, handoff.

## Deliverables
Architecture pack, Terraform/CDK, security assessment, cost model, runbook, DR evidence, knowledge-transfer sessions.

## Assumptions
Customer provides timely access to SMEs and nonproduction AWS environments.

## Exclusions
Application feature development, penetration testing, 24×7 managed operations.

## Acceptance
Deliverables approved and acceptance tests completed or risks formally accepted.
