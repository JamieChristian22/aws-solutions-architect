# Example Engagement — Northstar Commerce

Northstar operates a customer-facing commerce API with manual deployments, single-AZ database risk, and weak cost allocation. The recommended 6-week engagement moves the workload to a Multi-AZ managed architecture, introduces Terraform and CI, centralizes detection, defines a 60-minute RTO / 15-minute RPO, and establishes monthly FinOps governance.

Modeled monthly baseline: $42,000. Identified optimization backlog: $7,350/month (17.5%), explicitly modeled rather than claimed as live realized savings.
