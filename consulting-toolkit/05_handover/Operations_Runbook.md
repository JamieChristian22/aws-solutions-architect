# Operations Runbook

SEV-1: outage/security incident — acknowledge ≤15 min, assign incident commander, preserve timeline.  
SEV-2: degradation — acknowledge ≤30 min, triage service metrics/logs.  
Monthly: access review, backup evidence, cost review, alarm tests, patch/runtime review.  
Quarterly: DR exercise, Well-Architected action review, IAM review.
