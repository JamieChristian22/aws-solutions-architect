# KPI Catalog

| KPI | Definition |
|---|---|
| Events | count of valid event IDs |
| Sessions | distinct session IDs |
| Users | distinct non-null user IDs |
| Anonymous Visitors | distinct anonymous IDs |
| Purchase Sessions | sessions containing `purchase` |
| Session Conversion | purchase sessions / sessions |
| Revenue | sum revenue for purchase events |
| Revenue per Session | revenue / sessions |
| Cart Rate | add-to-cart sessions / product-view sessions |
| Checkout Completion | purchase sessions / checkout-start sessions |
| Events per Session | events / sessions |
| Search-to-Product View | sessions with product view after search / search sessions |
